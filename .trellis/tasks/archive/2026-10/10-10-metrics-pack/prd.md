# 指标增强包:P50/P95 + 连续异常 + 错误分布 + 抖动

> 来源:grill-me 拷问(2026-10-10,"还有什么指标或者配置建议增加的吗"),指标侧 6 选 4 全上,P99 明确不做。

## Goal

在现有聚合层上新增四项指标,让"慢在哪、挂没挂、为什么挂、稳不稳"四个问题各有数字可依——全部跟随来源筛选口径,三端(web 统计卡/TUI 详情/HTML 报告)一致展示。

## Background / Confirmed Facts(代码取证)

- 四项指标全部可从现有 `results/*.jsonl` 明细推导,零新存储字段、零探针改动。
- 聚合层入口统一:`store.Stats`(分类计数)与新增聚合共窗口/revision/source 过滤——`inWindow(r, min, source)` 已参数化(10-10-stats-by-source)。
- 均值现有 `AvgOnOK`;分位数需收集窗口内成功样本的 TTFT/Total 列表后排序取位,单对象 ≤20000 条,内存可承受。
- 连续计数需"最新在前"遍历到首个翻转;抖动需相邻比较(取消样本跳过,与分母口径一致)。
- 展示层:web `renderStats` 卡片数组、TUI `detail.statsBlock`、报告 `report.tmpl` cards + `reportTmplFuncs`,三处加行即可;来源/窗口/版本筛选管道已通。

## Requirements

### R1 P50/P95 分位数(成功样本)

- 对象:窗口/revision/source 过滤后的 **ok 样本**;两个维度:TTFT(排除 TTFT 为 nil 的样本)、总耗时。
- 算法:排序取最近邻秩(样本数 <20 时如实返回,不做插值美化);样本数 0 → null。
- 展示:web 统计卡「TTFT P50/P95」「总耗时 P50/P95」(与均值并列);TUI 统计行;报告统计卡。P99 不做(5 分钟采样下无统计意义,拷问决议)。

### R2 连续异常计数

- 定义:从最新样本向回数,直到首个结果翻转;输出当前连续失败次数与连续成功次数(其一必为 0)。
- 口径:跳过 cancelled(取消不是结果);按来源过滤(选手动时只看手动序列的连续性);快照时刻语义,不落库。
- 展示:概览卡(仅连续失败 ≥2 时显示「连败 N」角标)、详情统计区、报告头部状态旁。连续失败 ≥阈值 的高亮提示属于任务②(全局设置包),本任务只出数字。

### R3 错误细分分布

- 定义:窗口内非 ok 样本按 10 类 status 的计数与占非 ok 总数比例。
- 展示:详情统计区一行紧凑摘要(如 `错误分布:429×12 · conn×3 · abort×1`)+ web 悬停/展开明细;报告统计卡下补一行。零非 ok 样本不显示。

### R4 抖动/稳定性

- 定义:按时间正序相邻样本结果翻转次数 / 可比较对数,0=纹丝不动,1=每测必翻;cancelled 跳过不计对。
- 展示:详情统计区「抖动 x%」+定性档位(<5% 稳定 / 5-20% 波动 / >20% 频繁翻转,仅文案);报告同。

### R5 口径与三端一致

- 四项全部吃现有筛选(时间窗/revision/source),与统计卡同源同刷;无样本 → "—"/"暂无样本",绝不显示 0。
- 文案中文,与现有措辞风格一致;README 指标清单与 REQUIREMENTS §3.1 表同步补行。

## Acceptance Criteria

- [ ] A1 分位数数学:fixture {100,200,300,10000}ms → P50=250(平均于中位秩,最近邻秩实现取 200 或 250 按选定算法锁定并文档化)、P95=10000;nil TTFT 样本不影响总耗时分位数(store 单测)。
- [ ] A2 连续计数:fixture [失败,失败,成功,失败] → 连败 2 连成 0;取消样本穿插不打断计数;source=manual 时只看手动序列(store 单测)。
- [ ] A3 错误分布:混合 fixture 的各类计数与占比正确;全 ok 时不输出分布(store 单测)。
- [ ] A4 抖动:序列 [成,成,败,败,成] → 翻转 2/4 对=50%;全同结果=0%;样本 <2 → null(store 单测)。
- [ ] A5 三端展示:web 统计卡含分位数与抖动、概览卡连败角标;TUI 统计行含新指标;报告 HTML 含新卡(各端渲染测试或冒烟)。
- [ ] A6 筛选跟随:切来源/窗口后新指标随统计卡同刷(冒烟)。
- [ ] A7 回归:gofmt/vet/`go test ./... -race` 全绿;README/REQUIREMENTS §3.1 补行完成。
